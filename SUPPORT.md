# Support

Hearth is a personal Omarchy plugin shared publicly as a courtesy.

## Expectations

- **Best effort only.** There is no SLA, no guaranteed response time, and no commitment to implement feature requests.
- Issues may be closed without a fix when they are out of scope, duplicates, or not actionable.
- Security reports: please use [GitHub private vulnerability reporting](https://github.com/primo-marino/omarchy-hearth/security/advisories/new) if available, or open a minimal issue without secrets.

## Before opening an issue

1. Confirm you are on a recent Omarchy + Hyprland setup and Hearth is enabled (`omarchy plugin list`).
2. Include Omarchy/Hearth versions (or git commit), Home Assistant version, and the failing entity/action when relevant.
3. Do **not** paste tokens, long-lived access tokens, or `secrets.json`.

Thanks for understanding — this is a side project.
